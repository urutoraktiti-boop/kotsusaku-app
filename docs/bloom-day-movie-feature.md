# 開花日 当日のムービー

開花日（試験日・目標日）の**当日にアプリを開いたとき**、ヒヨコが鈴を鳴らす短い動画
（「成し遂げる」）をポップアップで1回だけ流す機能。

カウントダウンの応援メッセージ（`bloom-countdown.js`）は「あと○日」を毎日届ける仕組みで、
その**いちばん最後＝当日**に置く、締めくくりの演出。

---

## 何が起きるか

| いつ | 何が出るか |
|---|---|
| 開花日の**当日**、その日はじめてアプリを開いたとき | ムービーのポップアップが自動で1回 |
| 同じ日に2回目以降開いたとき | **出ない**（見せるのは1回だけ） |
| 開花日の前日・翌日・未設定 | 出ない |
| 開花日を別の日に設定し直したとき | その新しい開花日の当日に、また1回出る |

閉じたあとでも、当日のうちは 🌸 アイコン（ストップウォッチの横）→ 応援メッセージの
「🎬 開花のムービーをもう一度」から見返せる。このボタンは**当日を見ているときだけ**出る。

### 音について

**最初は音が消えた状態で流れる。** 携帯もパソコンも「音つきの動画が勝手に鳴り出す」のを
ブラウザ側が止める決まりになっているため、まず音なしで再生し、
動画の右上の 🔇 を押すと音が出る（もう一度押すと消える）。

まれに音なしの自動再生すら止められる端末があるので、その場合は動画の上に大きな **▶** が出る。
押せば音つきで再生される。

## ファイル

| ファイル | 中身 |
|---|---|
| `assets/bloom/bloom-day.mp4` | 本体（720×1086・5秒・約450KB） |
| `assets/bloom/bloom-day.webm` | 予備（H.264を再生できないブラウザ用・約330KB） |
| `assets/bloom/bloom-day-poster.jpg` | 読み込み中に出す静止画（約38KB） |

**mp4とwebmの両方が通信されることはない。** ブラウザは自分が再生できる方を1つだけ取りに行く。
ほぼ全ての端末（iPhone・Android・パソコン）は mp4 を選ぶ。

動画は**先に手元へ保管する一覧（`sw.js` の `CACHE_FILES`）には入れていない**。
開花日が近くない大多数の人にまで毎回ダウンロードさせないため。
代わりに、**開花日の前日**にアプリを開いた時点でそっと先に取りに行く（`prefetchDayVideo`）。
通信量を節約する設定（Save-Data）の人には取りに行かない。

## コードの場所

すべて `bloom-countdown.js` の中（`window.BLOOM_CD` と同じ即時関数の中に置いてある。教訓#004）。

| 関数 | 役目 |
|---|---|
| `maybeAutoShowDayVideo()` | 当日かどうか・もう見たかどうかを見て、条件が合えば出す |
| `showDayVideo()` / `hideDayVideo()` | 出す・閉じる（閉じたら再生を止めて頭に戻す） |
| `playDayVideo(retryMuted)` | 再生を試す。音つきで断られたら音を消してもう一度だけ試す |
| `prefetchDayVideo()` | 前日に動画を先に取っておく |
| `buildDayVideoUi()` | ポップアップの見た目を作る（初回だけ） |

外から呼びたいときは `window.BLOOM_CD.showDayVideo()` / `.hideDayVideo()`。

### 「見た」の記録

`localStorage` の `kotsusaku-bloom-day-video-seen` に**開花日そのもの**（`exam-date` の値）を入れる。
日付を入れているので、開花日を変えれば自動的にまた出る。

記録するのは**閉じたときではなく、出した時点**。閉じずにアプリを終了した人にも二度は出さない。

### 重なり順（z-index）

| ポップアップ | z-index |
|---|---|
| **当日のムービー** | **25000**（いちばん上） |
| 応援メッセージのカード | 24500 |
| お知らせ（notice.json） | 24000 |

お知らせと同じ日に重なった場合、ムービーが手前に出る。閉じるとお知らせが残る。

## 直すときの注意

- `bloom-countdown.js` は「手元に保管したものを先に使う」ファイルなので、
  **中身を直したら `sw.js` の `CACHE_VERSION` を上げないと、利用者の端末では古いままになる**
  （`version.json` と `index.html` の `CURRENT_VERSION` も合わせて3か所）。
- ポップアップの箱には高さの上限とスクロールを必ず入れること（教訓#007）。
  確認は **320×568 から**始め、「一番下のボタンを実際に押して閉じられるか」まで見る。
- 動画を差し替えるときは、縦長（およそ 2:3）を前提に作ってある。
  横長の動画を入れると、小さい画面で上下に余白ができる。
