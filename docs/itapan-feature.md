# 🍞 イタパン表示（夜21時台）の仕組み

`itachacha`（🥦 正体不明育成記）ストーリーを選んでいる人に、**夜9時台のマスを🍞で光らせる**機能。
休止・再開のたびに触る場所が決まっているので、作業前にここを読むこと。

---

## 誰に・いつ出るか

| 条件 | 内容 |
|---|---|
| 対象の人 | 設定のストーリーで **🥦「正体不明育成記」（`itachacha`）** を選んでいる人だけ |
| 時間帯 | **21時台の後半3マス**（`m=40,50,60`）。マスの数字は「終わりの時刻」なので、実際は **21:30〜22:00** |
| 開催期間 | `_itapanPeriods()` の表で決まる（後述） |
| 本人の設定 | 設定画面の「🍞 夜のイタパン表示」トグル（`CUST.itapanShow`、初期値オン） |

**出る条件＝ 🥦ストーリー かつ 開催期間内 かつ トグルON**（全部そろったときだけ）。

### 出るもの（3つ）

1. マスがオレンジに光って点滅＋🍞アイコン … `kotsusaku.css` の `.block.itachacha-bread`
2. 21時の行の「まとめて入力」ボタンが🍞になる … `.hour-btn.itachacha-bread-btn`
3. その時間帯にマスをチェックすると一言トースト … `_ITAPAN_MSGS` / `checkItapanToast()`

## 休止・再開のやり方（ここだけ直せばよい）

`index.html` の `_itapanPeriods()` が**唯一の出どころ**。ここを直して配信すれば、**全員に一斉に効く**。
利用者が設定をいじる必要はない。

```js
function _itapanPeriods(){
  return [
    {from:'2025-01-01',until:'2026-09-15'}, // 第1期（2026-09-16から休止中）
  ];
}
```

- **休止する** … いま動いている期間の `until` を「最後に開催した日」にする
- **再開する** … `{from:'2026-11-01',until:''}` のように**期間を1つ足す**（`until:''` は当分ずっと開催）
- 過去の期間を残しておけば、**その頃の日付を見返したときは当時どおり🍞が光る**（記録として自然）

### なぜ「トグルの初期値を変える」やり方にしないのか

設定トグルの初期値をオフにして休止させると、**再開しても、一度でも設定を触った人はオフのまま**になる
（保存済みの設定が初期値より優先されるため）。
そこで「開催しているか（＝配る側が決める）」と「表示したいか（＝その人の好み）」を分け、
**両方そろったときだけ出す**形にしてある。

## 関係する場所（`index.html`）

| 名前 | 役割 |
|---|---|
| `_itapanPeriods()` | 開催期間の表。**休止・再開はここだけ直す** |
| `_isItapanPeriod(ds)` | その日付が開催期間内か |
| `_isItapanOn(ds)` | 出してよいか（🥦ストーリー＋期間内＋トグルON） |
| `_itachachaBlockClass(h,m)` | マスに `itachacha-bread` を付ける／付けない |
| `_itachachaLiveEmoji(h)` | 時間ボタンを🍞にする／しない |
| `checkItapanToast(m)` | 一言トースト（1日1マスにつき1回） |
| `_syncItapanTogUI()` | 設定画面のトグルの表示・押せる／押せないをそろえる |
| `CUST.itapanShow` | その人の設定（初期値 `true`）|

---

## 朝の🥦ライブ表示との関係

朝5時台・6時台が🥦で光る表示（`itachacha-live`）は**別もの**で、
**期間もトグルも持たず、🥦ストーリー中はいつでも出る**。
今回のオン・オフは**夜の🍞だけ**が対象。朝も同じようにしたくなったら、
`_itapanPeriods()` と同じ形の期間表と `CUST` のキーをもう1組作るのが素直。
